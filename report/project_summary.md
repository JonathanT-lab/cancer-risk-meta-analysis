# Project Summary

## Title
Cancer Risk Meta-Analysis of Incense Smoke Exposure and Cancer Risk

## Background
This project demonstrates a reproducible case-control meta-analysis workflow in R using the `meta` package.

## Workflow
- Imported study-level case-control count data from CSV
- Performed Mantel-Haenszel meta-analysis
- Generated forest plot
- Generated funnel plot
- Assessed publication bias using Egger's test where applicable

## Portfolio Value
This project demonstrates:
- R programming
- meta-analysis workflow development
- biomedical data analysis
- scientific visualization
- reproducible research structure
